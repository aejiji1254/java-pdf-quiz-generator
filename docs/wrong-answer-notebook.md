# 통합 오답노트

오답은 세션당 첫 시도 기준이다. 첫 오답 뒤 같은 세션에서 재시도로 맞혀도 그 세션 기록은 오답이다. 시도 횟수는 저장된 첫 답안 수이며 미응답과 세션 내부 재시도는 더하지 않는다.

문항 UUID를 기본 식별자로 사용한다. 부모-자식 연결마다 질문 문자열 완전 일치, 보기별 `SavedQuestion.optionKey`와 순서 일치, correctIndex 일치를 검사하고 통과한 연결만 반복 방식 union-find로 합친다. 해설·출처·페이지의 차이나 설명 유사성은 합치기 판단에 사용하지 않는다. 질문·보기 순서·정답 중 하나가 바뀌면 그 연결만 끊기고 이전 세트의 옛 문항은 별개로 남는다. 부모 세트/문항이 로컬에 없으면 연결이 끊기며 오류로 세지 않는다. 순환·자기참조는 재귀 없이 처리한다.

정복은 최신 첫 시도 기록부터 거꾸로 세어 연속 정답이 N회 이상인 상태다(기본 3, 조절 1~10). 한 번도 틀리지 않은 문제는 표시하지 않고 정복한 문제는 기본적으로 숨긴다. `정복 포함`으로 다시 볼 수 있다. 시간 순서는 answeredAt 오름차순, 동률이면 결과 ID 사전순, 그래도 같으면 문항 ID 순이다. 최신 기록은 이 순서의 역순이다. 최근 오답 순은 마지막 **오답** 시각을 사용하며 마지막 풀이 시각과 구분한다.

질문 요약은 표시만을 위해 공백을 합치고 60 code point로 자른 뒤 잘렸으면 …를 붙인다. 합치기에는 원래 질문을 사용한다.

대표/출제 문항은 세트 필터에 해당하는 소속이 있으면 그 세트에서 고른다. 그렇지 않으면 연결된 세트 중 createdAt이 최신인 세트를 쓰며 동률이면 세트 ID 사전순, 같은 세트의 여러 문항이면 문항 ID 순이다. 과목·세트 필터는 소속을 제한하며 통계는 연결된 전체 기록을 유지한다. 표의 툴팁에서 다른 소속도 볼 수 있다.

선택 문항은 대표 문항의 실제 세트별로 묶어 기존 QuizSession으로 순차 진행한다. 여러 기록에서 모인 복습이라 reviewOfResultId는 null이다. 각 세트 저장 후 다음 세트 계속/여기서 종료를 선택한다. 중간 종료·메인 이동·계속 대화상자 취소는 남은 큐를 버린다. 저장 실패는 현재 세트에서 멈추고 앞서 저장한 결과는 유지한다. 저장 성공 시 새 결과를 백그라운드 재집계한다.

조회는 바로 아래 일반 .json 파일만 읽고 세트를 한 번씩 읽어 캐시한다. 결과는 기존 엄격한 파서·5MB·UTF-8·파일명 검증과 validateAgainst를 통과해야 한다. 제외 결과 개수·최대 5개 이유와 읽을 수 없는 세트 안내를 표시한다. 결과 폴더가 없으면 만들지 않는다. 집계·필터는 읽기 전용이며 실제 사용자 풀이 저장만 기존 기능으로 새 결과를 생성한다.

새 테스트는 주입한 임시 저장소만 사용한다. `mvn test -Dtest=NotebookDataGuard -Dquiz.guard=true`는 실제 data/의 파일 목록·바이트·수정 시각을 읽어 자식 `mvn test` 전후 동일함을 검증한다. guard 자체는 일반 테스트 검색 대상에서 제외해 재귀 실행을 막는다. 200개 결과 성능 검증은 세트 읽기 횟수와 정확성으로 확인하고 실제 소요 시간은 출력만 하며 절대 시간 단정은 하지 않는다.
